# financial-chatbot
A simple Python chatbot that answers basic finance questions from given data and shows trends using graphs.
# Features
--> Answers basic finance-related questions.
--> Works with data using  Pandas and Numpy.
--> Plots graphs using Matplotlib to show trends.
--> Built in Jupyter Notebook for easy testing.
# Tech Used
--> Python
--> Jupyter Notebook
--> Pandas
--> Numpy
--> Matplotlib
